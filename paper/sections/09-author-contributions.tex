\textbf{Göktuğ Karaca} (joint first author, corresponding author)
designed the overall system architecture, authored the entire
embedded firmware for the Arduino Uno sensor node and the AI Thinker
ESP32-CAM camera node, implemented the Python USB-to-HTTP bridge,
and developed the cross-platform Flutter mobile and web application
including the Dashboard, Camera, Products, Alerts, and Settings
screens, their state management, the local sensor service, the
camera streaming layer, the in-memory product store, and the alert
engine. He further developed the tiled multi-QR recognition routine,
the pixel-level RGB ripeness classifier, the per-product risk-score
model, and the GitHub Pages and local-server deployment pipeline. He
authored the Methodology, Implementation, Algorithms, and Results
sections of this manuscript. The authorship of all firmware, bridge,
and application source is independently verifiable from the project's
git history.

\textbf{Sıla Özgel} (joint first author) contributed to system

preparation, and co-authored the Introduction, Related Work, and
Discussion sections.

\textbf{Ezgi Erdoğan} (joint first author) contributed to ESP32-CAM
hardware integration, QR-code design validation, and prototype

\textbf{Hilal Bizimyer}, \textbf{Defne Kaya}, \textbf{Nehir Okutur},
