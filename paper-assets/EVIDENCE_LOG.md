# Paper Asset Evidence Log

This folder is the canonical, time-stamped archive of all visual and
documentary evidence for the *Smart Fridge / Zero-Waste Food Management*
project.

Every asset is recorded with:

- **Filename** — descriptive, kept stable so links don't break
- **SHA-256 hash** — cryptographic fingerprint; a single bit changes → hash changes
- **Provenance** — original source, photographer (if known), WhatsApp uploader, date
- **Intended use** — whether the asset will appear in the IEEE paper or stays internal

The git commit that introduces this folder is itself a timestamp (the
commit SHA is signed by GitHub's infrastructure). For independent,
court-grade timestamping, paired `.ots` (OpenTimestamps / Bitcoin
blockchain) proofs are also included where generated.

## Verification protocol

To independently verify any asset in this folder:

```bash
# 1. SHA-256 of the file should match the value listed above
sha256sum paper-assets/hardware/01-arduino-hx711-breadboard-labeled.jpeg

# 2. The git commit that introduced the file is timestamped and signed
git log --follow paper-assets/hardware/01-arduino-hx711-breadboard-labeled.jpeg

# 3. The repository itself is mirrored at
#    https://github.com/krcgoktug/smart-fridge-team (private)
#    and a v1.0-goktug-final-contribution tag of the original public
#    code state is permanently archived at:
#    swh:1:snp:6de23248993c6626ef0a9776d6816fe9b2a9b3d1
#    (Software Heritage, 2026-06-28)
```
